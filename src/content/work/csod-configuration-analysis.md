Led a data-driven analysis initiative examining Cornerstone OnDemand (CSOD) learning management system configurations across Meta's enterprise learning environment to identify optimization opportunities and inform strategic decision-making.

**Analysis Approach:**

- Performed comprehensive analysis of Cornerstone LMS configurations across multiple user segments and learner types
- Examined course access patterns, enrollment data, and usage trends to identify inconsistencies and optimization opportunities
- Analyzed system configurations against best practices and organizational learning goals

**Tableau Dashboard Development:**

- Built dynamic Tableau dashboard visualizing usage trends across different learner types
- Created interactive visualizations enabling stakeholders to explore data patterns and trends
- Designed dashboard to inform strategic decisions about course access and configuration policies

**Key Deliverables:**

- Comprehensive configuration analysis report documenting current state and opportunities
- Interactive Tableau dashboard for ongoing usage monitoring
- Recommendations for policy changes regarding course access conventions

**Business Impact:**

- Delivered insights leading to significant policy changes regarding course access conventions
- Provided data-driven foundation for strategic learning technology decisions
- Created sustainable analytics framework for ongoing configuration monitoring

- Learning technology analysis (Cornerstone OnDemand/CSOD)
- Data visualization (Tableau)
- Strategic analysis and recommendations
